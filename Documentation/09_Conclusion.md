\# Conclusion



This project documents the deployment of a Windows Server 2022 Active Directory environment built in a virtual lab.



The environment includes Active Directory Domain Services (AD DS), DNS, Organizational Units, users and groups, Group Policy, file sharing, NTFS permissions, drive mapping, and PowerShell automation for common administrative tasks.



The configuration was verified using a Windows 11 client by joining the domain, signing in with domain accounts, and confirming that Group Policies and access permissions were applied correctly.



Building this lab gave me practical experience with Windows Server administration and Active Directory management.
