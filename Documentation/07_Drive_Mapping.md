# Drive Mapping



## Overview



A Group Policy Preference was configured to map the IT shared folder as a network drive. This allows users in the IT department to access the shared folder automatically after signing in.



---



## Configuration



- Configured a Drive Map using Group Policy Preferences

- Mapped the IT shared folder to drive **I:**

- Linked the policy to the appropriate Organizational Unit
