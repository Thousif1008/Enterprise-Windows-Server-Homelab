\# Client Testing



\## Overview



The client computer was used to verify the Active Directory environment, Group Policies, and security settings.



\---



\## Verification



\- Verified the client joined the domain

\- Verified domain user sign-in

\- Verified Group Policy restrictions

\- Verified department access restrictions
