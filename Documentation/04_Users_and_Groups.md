# Users and Groups



## Overview



After creating the Organizational Unit structure, user accounts and groups were added to the domain. PowerShell was used to create groups and import users in bulk, and the results were verified in Active Directory.



---



## Configuration



- Created Security Groups

- Created Distribution Groups

- Used PowerShell to create groups

- Imported users from a CSV file using PowerShell

- Verified the created users and groups
