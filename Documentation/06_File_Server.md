\# File Server



\## Overview



Department folders were created on the server to store shared files for different teams. NTFS permissions were configured using Security Groups so that users could access only the folders assigned to their department.



\---



\## Configuration



\- Created shared folders for IT, HR, and Finance

\- Configured NTFS permissions using Security Groups

\- Verified access for authorized users

\- Verified access was denied for unauthorized users
